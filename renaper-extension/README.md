# Prueba RENAPER

En Chrome o Edge, abrir `chrome://extensions` o `edge://extensions`, activar Modo de desarrollador y elegir Cargar descomprimida. Seleccionar esta carpeta. Recargar Brasil Coral, en la versión local o en https://gerg45.github.io/brasil-coral-salidas/.

Desde un pasajero con DNI, sexo F/M/X y nacimiento, pulsar Consultar RENAPER. La extensión abre el sitio oficial, completa los campos, envía su formulario normal y devuelve el texto mostrado. El reCAPTCHA sigue a cargo del sitio; no se fabrican tokens ni se evaden verificaciones. Si hay un desafío debe completarlo la persona. Solo se admite una consulta por vez, con vencimiento; no se reintenta en bucle.

La opción Consultar al guardar permite iniciar este flujo tras guardar una ficha completa. La importación de Excel no dispara consultas masivas. Los datos de consulta quedan temporalmente en la memoria de sesión de la extensión y se eliminan al responder o cerrar las pestañas. Un resultado no reconocido se muestra para revisión sin inventar una letra.

Prototipo no afiliado a RENAPER. No se comprobó con un DNI real. El servicio puede rechazar automatizaciones o cambiar su formulario. No disponible en Safari/iPad. Desactivar o quitar la extensión cuando termine la prueba.
