# Tomar lista desde iPad

1. Abrir la dirección de GitHub Pages en Safari y entrar con la cuenta Google autorizada.
2. Elegir **Tomar lista** y la salida correspondiente.
3. Buscar por nombre, documento, grupo o butaca. Se puede filtrar pendientes o menores.
4. Tocar **Marcar ingreso**. La fila pasa a verde cuando Firebase confirma el guardado. Puede desmarcarse si hubo un error.

El distintivo de menor usa la edad a la fecha de salida. Sin nacimiento o fecha de salida muestra Edad sin confirmar. El check es individual, incluso si la persona pertenece a un grupo.

La notebook y el iPad usan los mismos datos: no es necesario trasladar respaldos entre ambos. Se necesita Internet; ante un error, el ingreso no se muestra como confirmado y debe reintentarse. Cerrar sesión al terminar en equipos compartidos. Los respaldos JSON descargados contienen información privada.
